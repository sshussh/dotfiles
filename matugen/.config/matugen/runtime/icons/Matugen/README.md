# Matugen folder icon derivatives

The folder silhouettes and special-directory pictograms in this directory are
derived from Adwaita Icon Theme 50.0. The original package declares
`CC-BY-SA-3.0 OR LGPL-3.0-only`.

Only the five fixed Adwaita folder-blue values were replaced with Matugen
template expressions. Matugen regenerates the resulting SVG colors from the
active wallpaper while the user icon theme inherits all other artwork from
Adwaita.
